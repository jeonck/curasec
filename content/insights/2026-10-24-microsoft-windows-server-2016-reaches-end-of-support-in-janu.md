- **Engineer — Plan:** With roughly three months until the January 2027 deadline, audit your estate now for Windows Server 2016 instances and schedule migration to Server 2022/2025 or enroll in Extended Security Updates before the cutoff.
- **SOC/IR — Skip**
- **Leader — Plan:** Inventory Windows Server 2016 dependencies across the org this quarter, budget for migration or ESU licensing, and flag to IT ownership — unpatched post-EOL servers will widen audit exposure and increase breach risk from future unpatched CVEs.
