- **Engineer — Plan:** Server 2022 now receives security patches only (no new features) through October 2031; audit your Server 2022 fleet and add a migration milestone to a supported release before extended support ends.
- **SOC/IR — Skip**
- **Leader — Plan:** EOL transition for a widely deployed server OS is a budget and roadmap input — schedule a migration plan from Server 2022 well before the 2031 extended support cutoff to avoid compliance gaps and unsupported infrastructure risk.
